# 预算与无实验室仪器备用路线

状态日期：2026-08-29

> **独立产品预算更新：** 当前冻结清单见 `../hardware/bom/INDEPENDENT_PRODUCT_PROCUREMENT.md`。AFE 现在自带专用面包板、跳线、手动配置和独立 5 V-to-3.3 V 供电链，不再以另一个项目购物车会按时到货为前提。下面保留 MM420 与无实验室仪器路线；旧的 $86.63 共享物料预算已由新预算替代。

## 1. 已确认条件

- 截图中的 $137.75 购物车尚未下单，因此其中器件暂时不能记为库存。
- 当前只有一块 MSP-EXP430FR6989 LaunchPad。
- 电脑有 USB-A，可以直接使用 LaunchPad 随附/标准的 USB-A to Micro-USB 数据线。
- 计划购买 Klein Tools MM420 万用表。
- OSU 示波器、函数发生器和限流电源也许可以使用，但项目必须能在完全无法使用它们的情况下继续。
- 当前没有焊台和焊锡，但通风条件满足；面包板阶段不需要购买焊接系统。
- 已确认预算上限 $200 仅用于 AFE 项目采购；另一个项目的 $137.75 购物车和 Klein MM420 均在该上限之外单独核算。

## 2. MM420 是否合适

结论：**适合作为本项目第一台日常 DMM，建议保留选择。**

官方规格包括 4000-count、自动量程、True-RMS、DC/AC 电压和电流、电阻、连续性、二极管、电容、频率和温度；套装含表笔、热电偶、两节 AAA 电池和说明书。当前参考零售价约为 Lowe's $64.98 或 Home Depot $69.97。

它在本项目中的任务：

- 断电检查短路和连续性；
- 测量 3.3 V 电源和约 1.65 V VBIAS；
- 实测关键电阻和电位器；
- 记录 Phase 1 的 DC 输入/输出点；
- 检查二极管方向和电源极性。

它不能完成：

- 观察快速波形、振荡、上升沿或相位；
- 代替示波器验证滤波器频率响应；
- 作为校准级精密电压基准；
- 证明 ADC 的完整 INL/DNL、噪声和动态性能。

初学者安全提醒：测电压时表笔并联在节点和地之间；测电流时必须把万用表串入回路。**绝不能把处于电流档的表笔直接跨接在 3.3 V 和 GND 之间**，否则相当于短路电源。Phase 1 初期不需要测电流，先只使用 DC 电压、电阻和连续性档。

## 3. 已冻结的预算口径

用户已确认 $200 只覆盖 AFE 项目器件，不包含 MM420。这是可行且有充足余量的方案：

| 项目 | 预算 |
|---|---:|
| AFE Base Unit 独立产品本体 | $85.85 |
| 自动验证附件（ADS1115、连接线、故障注入器件） | $20.40 |
| 建议现在购买 A+B | $106.25 |
| 可替换 NUCLEO-G474RE 参考控制器 + USB 数据线 | 确认工具链后 $23.08 |
| A+B+C 全部购买 | $129.33 |
| 全部购买后项目预算余量 | $70.67 |
| MM420 | 项目预算外单独购买 |

建议：购买 A+B，但 NUCLEO-G474RE 在接受 STM32Cube 工具链后再购买；不为了花满预算立即购买其他设备。第二块板不再限定为 LaunchPad；参考控制器的角色和替代项见 `CONTROLLER_BOARD_SELECTION.md`。Labrador 仍须等 Windows 兼容性和 OSU 权限确认；焊台继续等到永久焊接阶段。

新金额不假设另一个项目提供面包板、公对公跳线、QT-to-header 线或 5 V 电源。22 AWG 固芯线、剥线钳、鳄鱼夹和热缩管仍可作为共享实验室工具，但不会成为 AFE 产品运行的隐藏依赖。

为减少 Adafruit 运费，可以与另一个项目合并结账，但 AFE 专属面包板、跳线、QT 线和 5 V 电源必须按新清单数量购买，并在账目/收货标签中归属 AFE。

三笔账保持独立：原项目购物车、MM420、AFE 新清单。跨项目合并结账可以节省运费，但记账和 BOM 归属不能混合。

## 4. 已确定的采购决定

- 保留 MM420 选择，下单时比较 Lowe's、Home Depot 和 Klein 官方零售商链接；
- 第二块板不限定型号；当前推荐NUCLEO-G474RE承担验证控制器角色，但须先确认是否接受STM32Cube工具链；
- 不买焊台、Labrador、AD9833、第二块 Perma-Proto 和 PCB 产品化件；
- AFE 核心半导体/精密无源件先保持购物清单，不和错误封装或随机套件互换；
- 原购物车和 AFE 采购最好分成两个订单/预算标签，即使从同一商家结账，也保留各项目归属。

## 5. OSU 仪器可用时的路线

1. Phase 1 在家用 MM420 完成 DC 安全和增益验证；
2. Phase 2 在 OSU 使用函数发生器和双通道示波器测截止频率、相位趋势、Schmitt 上下阈值和输出边沿；
3. 记录仪器型号、探头倍率、采样率、带宽限制、屏幕截图和原始 CSV；
4. 关键结果仍由 Python 自动分析，实验室仪器只提供可信原始数据。

## 6. OSU 仪器完全不可用时的路线

项目不会停止，而是转为“软件主导、有限低压硬件证据”的自动化验证平台。

### 仍能真实完成

- MM420 + 电位器的 Phase 1 DC sweep；
- 参考验证控制器ADC自动采样；
- PWM 经 RC 形成低速测试电压；
- UART + CRC + CSV 数据链；
- ADS1115与参考控制器ADC的低速DC对照，并将MSP430作为单独兼容profile复测；
- 增益、偏置、线性、饱和、阈值和迟滞的低速自动分析。

### 只能有限验证或暂缓声称

- 精确滤波器频率响应、相位和高频稳定性；
- 运放振荡、建立时间和快速瞬态；
- 比较器传播延迟和高速边沿；
- 精密噪声谱和带宽指标。

### 软件主线扩展

- 建立统一的 instrument/device adapter 接口，让数据可以来自真实串口、CSV 回放或仿真器；
- 为每条数据强制记录 `SYNTHETIC`、`SPICE_IDEAL`、`SPICE_MODEL`、`BENCH_DMM` 或 `BENCH_SCOPE` 来源标签；
- 添加 golden-data 回归测试、串口断包/坏 CRC/超时故障注入；
- 自动生成理论值、容差上下界、测量值、误差和 PASS/FAIL 报告；
- 使用 LTspice 批处理结果测试频率响应分析器，但明确标为仿真；
- 将硬件层设计成可插拔后端，将来获得 OSU 或个人仪器后无需重写分析平台。

这个转向不会伪装成“硬件已经验证”。作品集的重点将变成独立AFE产品、可追溯测试架构、数据质量、控制器无关自动化、仿真/实测证据隔离和多个兼容profile，而不是高频模拟性能声明或MSP430附属模块。

## 7. 下一道决策闸门

预算口径已冻结，但清单仍是“采购选型版”，不是已下单或已收货记录。下一步要按 `INDEPENDENT_PRODUCT_PROCUREMENT.md` 与 `independent-product-purchase.xlsx` 的链接，把A+B行落实到Adafruit和Mouser购物车，复核完整制造商料号、封装、库存、税运和交期；只计算AFE归属项目的最终含税运金额，不得超过$200。NUCLEO-G474RE保持`CONFIRM_TOOLCHAIN`，直到用户接受STM32Cube工具链。
