# TD-048 软件自动化价值关闭决定 — 2026-09-08

## 决定

TD-048 对当前项目里程碑关闭。所有者确认：AVS 已经在重复 DC 验证场景中承担
数据读取、质量处理、拟合计算、阈值判断、绘图/报告、批次历史和差异比较，
因此当前不再进行 Excel/已有脚本与 AVS 的人工配对计时。

人工记录保持 NOT_RUN，SW-VAL-002 改为 DEFERRED。该决定不表示 AVS 已经证明
具体节省比例、陌生用户效率提升或人工错误率下降。如果未来展示需要这些量化主张，
必须恢复真实操作者、等难度变体和配对记录，不能用机器耗时或测试覆盖率代替。

## 已有证据

[TD-048 软件预演](td-048-casepack-software-dry-run-2026-09-08.md)使用 5 个预先
冻结的 SYNTHETIC 案例和不调用 AVS 分析代码的有理数参考，核对了正常、超限、
异常点、证据不足和非法单位路径。CLI、四种可读报告、项目历史和比较结果一致，
最终 258 项针对性检查通过。

这足以支持以下项目表述：

> Analog Validation Studio 将重复模拟数据验证中的数据质量检查、工程计算、
> 验收判断、报告生成和运行比较整合为可重复、可追溯的自动化流程；
> 受控 CSV Replay 案例已经由独立参考核验。

当前不能写“节省 X% 时间”“降低 X% 人工错误”或“比 Excel 快 X 倍”。

## 下一产品阶段

TD-048 暴露的主要产品缺口是输入可复现性：项目快照保存配置和 Replay 路径，
运行结果保存记录引用，但运行目录没有保留 Replay 原文件。如果源文件被移动或修改，
历史结果无法仅靠运行包完整复盘。

下一阶段定为 TD-040C1 的第一小段：

- 仅覆盖离线 CSV Replay 项目运行；
- 在 create-new 运行目录内保留不可覆盖的输入副本；
- manifest 记录相对路径、字节数和 SHA-256；
- 验证加载时的缺失、篡改和路径安全；
- 保持既有 manifest v1/v2 完全可读，不修改历史产物；
- 暂不混入 READ/LIVE、Dashboard、曲线叠加、签名或硬件功能。

本决定没有修改运行时、公共 API 或历史输出。没有提交、推送、发布、串口枚举、
串口访问、MSP430/AFE/实验室仪器操作或硬件采购。

证据仍严格区分 SYNTHETIC、CSV_REPLAY、HOST_TEST、SPICE_IDEAL、
BENCH_CONTROLLER 和 BENCH。软件自动化 PASS 不构成硬件验证。
